# Code of Conduct

## Our Pledge
We as team members pledge to make participation in EchoMem a respectful, harassment-free experience for everyone.

## Standards
- Use welcoming, inclusive language
- Respect differing viewpoints and experience levels (we are all learning)
- Accept constructive criticism gracefully
- Focus on what is best for the project and for each other's learning
- Show empathy toward teammates

## Responsibilities
- Merge only reviewed, tested code
- Ask for help when blocked; do not silently struggle for days
- Communicate early if a deliverable will be late
- Share knowledge; pair-program on hard modules
- Be honest in standups about progress and blockers

## Scope
This code of conduct applies to the GitHub repo, chat group, meetings, and any project-related communication.

## Enforcement
If a team member violates this code, the other members will raise it in the next Friday retro and resolve it together. If a serious issue persists, escalate to the project guide.
